# @coldmind/http-routes

HTTP route contracts in the shape of rpc contracts. A route has a method, a path (`/orders/:id`,
`/files/*rest`) and the same schemas an rpc proc has; the route table matches requests with a fixed
precedence; the contract converts to the rpc contract a server registers, so auth, sessions, access,
validation and deadlines apply to HTTP like to any other call. No I/O, no dependencies beyond
`@coldmind/rpc` and `@coldmind/model`.

```ts
import { str } from "@coldmind/model";
import { RouteTable, httpContract } from "@coldmind/http-routes";

const orders = httpContract("orders", {
  get:    { method: "GET",  path: "/orders/:id", params: { id: str() }, result: { sku: str() }, access: "public" },
  create: { method: "POST", path: "/orders", body: { sku: str() }, status: 201 },
});

new RouteTable([orders]).match("GET", "/orders/42");
// { kind: "match", route: { topic: "http/orders/get", proc: "http.orders.get", … }, params: { id: "42" } }
```

## API

- **`httpContract(name, routes, { doc })`**: declares and validates a group. `HttpRouteDef`: `method`
  (`GET POST PUT PATCH DELETE`), `path`, `params`, `query`, `headers`, `body`, `result`, `chunk`,
  `stream` (`"chunked" | "sse"`), `status` (default 200), `access`, `doc`, `idempotent`, `noTimeout`.
  `params` keys must equal the path parameters; `GET` has no body; names are topic-safe.
- **`RouteTable`**: `new RouteTable(contracts)`, `match(method, rawPath)` returns `match` (route, decoded
  params, `viaHead`), `method-not-allowed` (with `allow`), `not-found` or `bad-path`. Literal beats
  parameter beats wildcard, left to right. `HEAD` falls back to `GET`. Duplicate method and path
  shapes throw. `procContracts()` converts every group.
- **`procContractOf(contract)`**: the rpc contract `http.<name>` whose procs take
  `{ params, query?, headers?, body? }`. A route `body` must be a field, a shape or a model.
- **`coerceFields(schema, raw)`**: turns URL and header strings into numbers, booleans and lists by field kind.
- **Decorators**: `@httpController(name)`, `@get/@post/@put/@patch/@del(path, def)`, `@httpRoute(def)`,
  `routesOf(Class)`, `routeHandlersOf(instance)`. Bun native and `experimentalDecorators`.
- **`describeRoutes(contract)`**: the group as JSON data: method, path, topic, access, status, schemas.
- **`compilePath`, `matchPath`, `compareSpecificity`**: the path primitives.

Paths are matched on the percent-encoded request path and each segment is decoded on its own, so an
encoded `/` stays inside its segment. Parameters never become part of a topic: the topic of a route is
fixed, `http/<contract>/<route>`.

Serving and answering routes: [`@coldmind/net.adapter.http`](../../net/adapter/http/README.md) and its
[guide](../../net/adapter/http/docs/guide.md). For LLMs: [`llms.txt`](llms.txt).
