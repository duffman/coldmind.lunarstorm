    Interface InjectDecorator

    Injectable fields, auto-accessors, setters and legacy constructor parameters. Legacy TypeScript permits two-argument property decorators on methods too; this indistinguishable syntax is rejected by the runtime placement guard. TC39 contexts and explicit legacy descriptors are checked here.
