    Properties

    autoInject

    autoInject: boolean | AutoInjectOptions

    Builds unregistered classes on demand. When on, resolving a class token that has no registration registers the class on the resolving container (kindTag: 'auto') and resolves it. A scope inherits the setting until it sets its own.

    buildTimeout

    buildTimeout: number | null | undefined

    Async build deadline inherited by children; undefined inherits and null explicitly disables it.

    Readonlyidentity

    identity: ScopeIdentity

    Identity of this scope: id, kind, and tenant or request id.

    ReadonlyisDisposed

    isDisposed: boolean

    True once dispose has run on this container.

    ReadonlyscopeType

    scopeType: ScopeType

    The scope kind.

    Readonlysignal

    signal: AbortSignal

    Build signal in a factory/hook context, otherwise this container's lifetime signal.
